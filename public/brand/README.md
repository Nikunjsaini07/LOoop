# Readwell brand

Readwell is the product name as of 20 October 2026.

`readwell-original.png` is the user's supplied 1536 × 1024 logo, copied without changes. `components/BrandLogo.tsx` frames only the book symbol with an SVG viewport. An SVG luminance-to-alpha filter renders its white paper transparent against the page background. The header pairs this 28 × 28 icon with “Readwell” in the previous wordmark's Cal Sans font, 20px on desktop and 18px on small screens.

`public/favicon.svg` is a compact vector rendering of the supplied book-shaped R, also used on the missing-article screen. Interface typography remains Cal Sans for display, Geist for body, and Instrument Serif for editorial emphasis.

Internal storage keys, reader identity hashes and deployed infrastructure names retain their original identifiers to preserve existing data.
